== 공통 규격

=== Base URL

|===
| 환경 | Base URL

| 로컬 | `http://localhost:8080`
| 운영 | 🔶 도메인 확정 후 기입
|===

=== 인증

**이 서비스는 토스 로그인을 쓰지 않는다.** 전 구간을 익명키 하나로 식별한다.

|===
| 헤더 | 값 | 필수

| `X-Anonymous-Key` | 클라 `getAnonymousKey()` 의 hash | 인증이 필요한 엔드포인트에서 필수
|===

익명키는 **미니앱마다 고유**하고 **같은 사용자는 항상 같은 값**을 받는다 — 기기가 아니라
토스 계정 기준이다. 비밀이 아니라 식별자이지만, 이 서비스에서는 **아는 사람이 곧 그 사용자**가
되므로 취급 수준은 자격증명에 준한다(원문을 로그·응답에 남기지 않는다).

==== 인증 게이트

기본값은 **인증 필요**이며 공개 경로만 열거한다.

|===
| 상황 | 응답

| 헤더 없음 | 401 `AUTH_001`
| 헤더 있음·형식 위반 | 401 `AUTH_002`
| 공개 경로 | 헤더 없이도 200 (있어도 무시)
|===

CORS preflight(`OPTIONS`)는 게이트를 거치지 않는다 — 브라우저가 preflight 에 커스텀 헤더를
싣지 않아 원리상 인증될 수 없기 때문이다.

=== 에러 응답

모든 에러는 아래 형태로 내려온다.

[source,json]
----
{
  "code": "COMMON_001",
  "message": "유효하지 않은 입력값입니다."
}
----

|===
| 코드 | HTTP | 의미

| `COMMON_001` | 400 | 유효하지 않은 입력값
| `COMMON_002` | 500 | 서버 내부 오류
| `AUTH_001` | 401 | 인증 필요
| `AUTH_002` | 401 | 유효하지 않은 인증 정보
| `AUTH_003` | 403 | 접근 권한 없음
|===

=== 시간대

응답의 시각은 ISO-8601 문자열이며 서버 기준 시간대는 `Asia/Seoul` 이다.
