=== 인증

**이 서비스는 토스 로그인을 쓰지 않는다.** 익명키로 로그인(부트스트랩)하고,
이후 전 API 는 **JWT Bearer 토큰**으로 인증한다.

|===
| 헤더 | 어디서 | 값

| `Authorization` | **인증 필요 엔드포인트 전부** | `Bearer {accessToken}` — 부트스트랩이 발급
| `X-Anonymous-Key` | **부트스트랩에서만** | 클라 `getAnonymousKey()` 의 hash
|===

* access 토큰은 **30분** 유효. 만료(`AUTH_004`)를 받으면 `POST /api/v1/auth/refresh` 로
  갱신 후 **1회만** 재시도한다 — 이 흐름은 HTTP 인터셉터 한 곳에 둔다(진입 절 참조).
* refresh 토큰은 **14일·회전식** — 갱신할 때마다 새 값으로 바뀌고 이전 값은 즉시 무효다.
  로컬에만 보관하고 어떤 로그·화면에도 남기지 않는다.
* 익명키는 **미니앱마다 고유**하고 같은 사용자는 항상 같은 값을 받는다(토스 계정 기준).
  아는 사람이 곧 그 사용자가 되므로 취급 수준은 자격증명에 준한다 — 부트스트랩 외에는 실지 않는다.

==== 인증 게이트

기본값은 **인증 필요**이며 공개 경로만 열거한다.

|===
| 상황 | 응답 | 프론트 행동

| 토큰 없음 | 401 `AUTH_001` | 부트스트랩 재실행 후 1회 재시도
| 토큰 무효(서명·형식) | 401 `AUTH_002` | 재시도 무익 — 부트스트랩 재로그인
| **토큰 만료** | **401 `AUTH_004`** | **refresh 후 1회 재시도**
| 공개 경로 | 자격 증명 없이도 200 (있어도 무시) | —
|===

CORS preflight(`OPTIONS`)는 게이트를 거치지 않는다 — 브라우저가 preflight 에 커스텀 헤더를
싣지 않아 원리상 인증될 수 없기 때문이다.

=== 에러 응답

모든 에러는 아래 형태로 내려온다.

[source,json]
----
{
  "code": "COMMON_001",
  "message": "유효하지 않은 입력값입니다."
}
----

|===
| 코드 | HTTP | 의미

| `COMMON_001` | 400 | 유효하지 않은 입력값
| `COMMON_002` | 500 | 서버 내부 오류
| `AUTH_001` | 401 | 인증 필요
| `AUTH_002` | 401 | 유효하지 않은 인증 정보
| `AUTH_003` | 403 | 접근 권한 없음 (미사용 — 결제 403 은 `PAY_001`/`PAY_007`)
| `AUTH_004` | 401 | 만료된 access 토큰 → refresh 후 재시도
| `AUTH_005` | 401 | 무효한 refresh (만료·재사용) → 재로그인
| `PAY_001`~`PAY_007` | — | 결제·이용권 절 참조
|===

=== 시간대

응답의 시각은 ISO-8601 문자열이며 서버 기준 시간대는 `Asia/Seoul` 이다.
